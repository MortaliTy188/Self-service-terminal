# WebSocket Подключения

## 📡 Обзор

Приложение использует несколько WebSocket соединений для получения обновлений в реальном времени без перезагрузки страницы.

## 🔌 Активные WebSocket Соединения

### 1. `/ws/orders` - События заказов

**Где подключено:**

- `OrdersPage.vue` (админ-панель)
- `MainPage.vue` (страница покупки)

**События:**

- `order_created` - новый заказ создан
- `order_updated` - заказ обновлён
- `order_status_changed` - изменение статуса заказа
- `cart_updated` - изменена корзина для стола
- `table_changed` - изменён номер стола устройства

**Что обновляется:**

- ✅ Список заказов в админ-панели (добавление/обновление без перезагрузки)
- ✅ Статус заказов в реальном времени
- ✅ Корзина на планшетах

### 2. `/ws/notifications` - Уведомления (новые)

**Где подключено:**

- `OrdersPage.vue` (админ-панель)

**События:**

- `notification_new` - новое уведомление (вызов официанта, запрос оплаты, проблема)

**Что обновляется:**

- ✅ Уведомления о вызове официанта
- ✅ Уведомления о запросе оплаты
- ✅ Уведомления о проблемах

### 3. `/ws/notifications/all` - Полный список уведомлений

**Где подключено:**

- `OrdersPage.vue` (админ-панель)

**События:**

- `notifications_list` - массив всех уведомлений при подключении

**Что обновляется:**

- ✅ Вкладка "Все уведомления" в админ-панели
- ✅ Список всех уведомлений (новых и обработанных)

### 4. `/ws/deviceStatus` - Статус устройств

**Где подключено:**

- `OrdersPage.vue` (админ-панель)

**События:**

- `device_status` - обновление активности, батареи, времени последней активности

**Что обновляется:**

- ✅ Статус устройства (активно/неактивно)
- ✅ Уровень батареи устройства
- ✅ Время последней активности

### 5. `/ws/images` - События изображений

**Где подключено:**

- `OrdersPage.vue` (админ-панель)
- `Greetings.vue` (страница приветствия) ⭐ **НОВОЕ**
- `MainPage.vue` (страница покупки) ⭐ **НОВОЕ**

**События:**

- `image_updated` - смена стартовой картинки

**Что обновляется:**

- ✅ Изображение заставки на странице приветствия (без перезагрузки)
- ✅ Фоновое изображение меняется мгновенно на всех устройствах

### 6. `/ws/menu` - События меню

**Где подключено:**

- `OrdersPage.vue` (админ-панель)
- `MainPage.vue` (страница покупки) ⭐ **НОВОЕ**

**События:**

- `menu_item_status_changed` - изменение активности блюда (is_active)

**Что обновляется:**

- ✅ Статус блюда в меню (активно/неактивно)
- ✅ Визуальное обозначение недоступных блюд
- ✅ Блюда плавно становятся серыми с надписью "Нет в наличии"
- ✅ Блокировка добавления в корзину неактивных блюд

## 🎯 Преимущества

### Без WebSocket (раньше):

❌ Нужно перезагружать страницу для обновления
❌ Задержка в отображении новых заказов
❌ Пользователи не видят изменения в меню
❌ Изображения не обновляются автоматически

### С WebSocket (сейчас):

✅ Автоматическое обновление без перезагрузки
✅ Мгновенное отображение новых заказов
✅ Изменения в меню видны сразу на всех устройствах
✅ Изображения обновляются в реальном времени
✅ Плавные анимации при изменениях
✅ Визуальное обозначение недоступных блюд

## 🔄 Жизненный цикл подключения

```javascript
// При монтировании компонента
onMounted(() => {
  webSocketStore.connect() // /ws/orders
  webSocketStore.connectMenuSocket() // /ws/menu
  webSocketStore.connectImagesSocket() // /ws/images
})

// При размонтировании компонента
onUnmounted(() => {
  webSocketStore.disconnect()
  webSocketStore.disconnectMenuSocket()
  webSocketStore.disconnectImagesSocket()
})
```

## 🛠️ Обработка ошибок

- Автоматическое переподключение при разрыве соединения
- Exponential backoff (увеличение задержки между попытками)
- Максимум 5 попыток переподключения
- Fallback на polling (каждые 5 секунд) если WebSocket недоступен


## 🎨 Визуальные эффекты

### Недоступные блюда:

- Серый фильтр (grayscale 70%)
- Полупрозрачность (opacity 0.6)
- Оверлей "Нет в наличии"
- Блокировка клика
- Плавная анимация появления (fadeIn 0.3s)

### Обновление заказов:

- Новые заказы появляются сверху списка
- Плавная анимация добавления
- Уведомление о новом заказе

### Обновление изображения:

- Мгновенная смена фона
- Без мерцания
- Работает на всех открытых страницах
